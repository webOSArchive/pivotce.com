Yo! We heard you like open sourced webOS so [LG open sourced](http://www.lgnewsroom.com/2018/03/webos-enters-next-phase-as-global-platform-under-lgs-stewardship/) the open source of webOS!

Ok, so that’s not entirely accurate since [LG purchased the closed source webOS code](https://www.theverge.com/2013/2/25/4027018/lg-buys-webos-smart-tv) from HP after [they open sourced](https://www.theverge.com/2012/1/25/2732672/open-webos-10-announced)…well…bits and pieces of it back in 2012. So no, you’re not stuck in a Doctor Strange time loop.

webOS *has* been open sourced before but not by LG.  This news comes as a shock to the current legacy webOS community still rocking Pre 3s and waiting for LuneOS to reach “driver” status.  The community hasn’t poured through the code as of yet but it immediately begs certain questions:

1. Will the work on LuneOS be helped or hindered by additional LG open source code which LG had already been committing too for some time (though they have missed some of their promised bits for a while)?
2. What hardware limitations are there for use of the software? Still looking for that [webOS toaster](https://www.youtube.com/watch?v=QnZDZEMyWfo&feature=youtu.be)…
3. How flexible (read: portable) is it?
4. How complete is it?  HP’s open source webOS was decidedly incomplete…

We’ll keep you updated on the developments on this as they become available.  For now, the conversation has started on the forums so feel free to [chime in](https://forums.webosnation.com/open-webos-general-discussion/332023-webos-ready-move-beyond-tvs-says-lg.html).
