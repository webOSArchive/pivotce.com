Without further delay, you can find the newest LuneOS stable builds [here](http://build.webos-ports.org/luneos-stable/images/).  This release is code-named Antoccino and is the second stable release following our initial release named Affogato. Yes, there are other devices in the build folder which are available, however, the Nexus 4 and HP TouchPad are still the only two devices officially supported at this time. Test the other builds **AT YOUR OWN RISK**.

**Please note that the [installation instructions for the TouchPad](http://webos-ports.org/wiki/Install_WOP_for_Tenderloin) have changed.**  You *must* recreate the partition LuneOS requires for installation. We recommend using the webOS app, [Tailor](http://forums.webosnation.com/webos-internals/304871-tailor-device-live-partition-filesystem-editor-beta-testing.html), because it is the easiest method. This is in preparation for a forthcoming semi-automated installation procedure. We’ll discuss those details when the product is ready for testing but for now just follow the guide.

We’ve made quite a few changes and ~~will release the full changelog soon~~ you can read the major ones [here](http://forums.webosnation.com/luneos/328670-pivotce-next-luneos-stable-release-available-antoccino.html#post3425734).

As a reminder, there are three things we need and want from you as a tester:

1. [Sign up for the bug tracker](http://issues.webos-ports.org/projects/ports/issues?set_filter=1)

2. [Get involved](/2014/09/22/webos-ports-help-wanted/) and

3. [Join the mailing list](http://lists.webos-ports.org/mailman/options/luneos-dev)

Don’t forget to contact us with any questions and feel free to [join the discussion on the webOS Nation forums](http://forums.webosnation.com/luneos/328670-pivotce-next-luneos-release-builds-available-antoccino.html). Also, continue spreading the word!
