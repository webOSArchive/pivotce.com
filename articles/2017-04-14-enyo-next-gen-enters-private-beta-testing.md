# Enyo Next-Gen enters private beta testing

[EnyoJS](http://enyojs.com/) is the javascript frame work used by webOS developers to create applications for both the legacy OS, [LuneOS](https://pivotce.com/tag/luneos/) and LG’s TV OS.

Those following along will recall that the development team had moved onto a new version based on [React.js](https://facebook.github.io/react/) and that this had potential [implications for LuneOS](https://pivotce.com/2017/01/25/a-future-javascript-framework-for-luneos-demos-wanted/).

The Enyo team have just [begun a private beta of the next generation Enyo](http://forums.enyojs.com/discussion/comment/10681/#Comment_10681). What we know is that with LG’s TV arm as their main customer, the focus remains on TV sized apps. Though increased support for mobile is planned, it is currently limited. Also, the framework will have a new name when publicly released.

This next generation of Enyo will be of interest to those currently building apps with the platform, but may also attract developers already experienced with ReactJS.

For those engaging with this testing phase, we’d be interested in any comments. The webOS Ports team will no doubt also be interested in any [app demos built with it](http://webos-ports.org/wiki/New_JavaScript_framework) too. You can comment at [webOS Nation](http://forums.webosnation.com/webos-development/331121-pivotce-enyo-2-7-released-next-generation-plans.html#post3450272).
